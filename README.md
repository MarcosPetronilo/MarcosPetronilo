Energy (BLE), together with the embedded firmware in C (ESP32 / ESP-IDF). Handles device

Published on Google Play and the App Store.

**Time Work** — time-tracking app built in React Native with its own backend.
Published on Google Play and the App Store.

**Glucose monitoring app** — React Native (Expo) with a Java (Spring Boot) backend.
Currently in development.

**Sensor data dashboard** — web panel for visualizing the readings collected over BLE.

**[smartsensordesign.com](https://smartsensordesign.com)** — company website, built with
